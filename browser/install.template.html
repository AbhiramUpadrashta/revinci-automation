Test your Revinci workspace from the browser

Nothing to install. Paste the runner into your Revinci tab once and it drives the screens step by step, using the login you already have.

tessla-workspace-dev.revinci.ai

Set it up once in this browser

About a minute. Works in Arc, Chrome, Edge and Brave.

  1. Open Revinci and log in as you normally do, for example https://tessla-workspace-dev.revinci.ai/dashboard.
  2. Open the browser console in that tab: ⌥ ⌘ J on Mac, Ctrl Shift J on Windows. In Arc you can also right-click the page and choose Inspect, then the Console tab.
  3. Copy the runner and paste it into the console, then press Enter. If the console asks, type allow pasting and press Enter first, then paste again.
    The test panel opens over Revinci straight away. A copy is saved in this browser so you don't need to paste again.

Start it next time

Pick whichever is easier. Both need you to be logged in to Revinci in that tab.

  1. Bookmark: drag this button to your bookmarks bar (⌘ Shift B shows it), then click it on any Revinci page.

What it tests

Tick any mix in the panel. Each run tags its records with a code like ATK3F9Q, so runs never collide and the order can reuse the account and product created earlier in the same run.

Admin setup

  • Currency and exchange rate
  • Unit of measure
  • Attribute and attribute group
  • Price profile and cost profile
  • Customer account

API key

  • Checks Settings ▸ API Keys
  • Reuses a saved key or one you paste
  • Creates one only if none is active
  • Shows the key in the panel

Product setup

  • Product, bundle, option, option group
  • Feature, feature offering, agent feature
  • Product with features or offerings
  • Simple and workflow agents

Quote · Order · Entitlement

  • Quote → bag → finalize → lifecycle
  • Order → bag → finalize
  • Activate entitlement, map external ID
  • Send a usage event to the plan

API testing

  • Auth checks, including bad keys
  • Accounts, entitlements, plans, rating
  • Wallets, carryover, consumption rules
  • Usage ingest, single and bulk

Good to know

  • The runner never asks for your password. It works only in a tab where you're already logged in.
  • It creates real records in the workspace you run it on. Use the dev workspace.
  • Revinci allows one active API key and shows its secret only once. Paste your existing key into the panel, or tick Revoke & recreate to replace it. The key is saved only in your browser.
  • Download the report from the panel when a run finishes. Failed steps show the screen they stopped on.
  • If your session expires mid-run, log in again and run the remaining options.
